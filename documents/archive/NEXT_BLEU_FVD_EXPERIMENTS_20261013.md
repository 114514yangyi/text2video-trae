# 下一轮 BLEU / FVD 实验方案

日期：2026-10-13。状态：研究建议，未实施新训练。用户请求多条实验路径，目标是提升手语生成的 BLEU、降低 FVD。

## 1. 目标、边界与评测约定

- 固定已训练的每帧1-token、1024维VAE，冻结缓存和统计；latent扩散，网络输出x0。
- 主生成mT5继续可训练；条件与监督来自现有文本—视频配对。不加pose、gloss、光流、参考条件。冻结VAE固有解码锚点照旧。
- 所有回译使用SignMbart和现有RefSign指标协议。独立训练辅助latent→text模型不改变回译评测模型。
- 用户未指定BLEU阶数：本方案同时报告BLEU-1/2/3/4，重点验证BLEU-4及完整句子，而不是只优化BLEU-1。期限和投稿目标未指定，不影响本轮技术排序；GPU预算此前用户允许充分使用。
- 本地字段`fvd`实际使用R(2+1)D-18/Kinetics400特征、整段均匀抽16帧，建议报告注明FD-R2Plus1D-16，不能与外部I3D-FVD数值横比。先保持旧口径；新增指标须整表重算。
- 既有64条dev用于筛选；候选扩展至按当前max_num_frames=256过滤的全部518条dev（原始519，1条被过滤），三个生成seed分别计算指标再汇总，三个训练seed验证最终方法。不能把同一句多个seed的生成当作更多独立句子。
- 结构/损失消融先固定oracle长度以隔离原因；最终部署用文本预测长度，两个口径分表。最终test只在方案和超参确定后使用。

B−A-only：BLEU-1 +0.530，BLEU-4 −0.368，ROUGE-L +0.976，FD −1.348。BLEU-1差的95% bootstrap区间[-2.33,+3.25]，ROUGE差[-2.15,+3.84]；没有可靠证据证明B优于等预算A。现有bootstrap未计算BLEU-4差，下一轮应补充。

B内部正确−打乱文本：BLEU-1 +4.05、ROUGE +4.76，区间均高于0，说明B使用了文本。不能据此证明它比A具有显著更强的文本依赖，后者需要差中之差检验。B还不是全指标优胜者。

训练曲线复核：B的语义损失在1–1000、2001–3000、4001–5000步平均为.44264/.36802/.32939，仍在下降。此前对话引用的约.9来自smoke，不能代替正式曲线；“3000步后平台”证据不足。B dev MSE从.02165升至.02425，A-only末值.02067；它提示目标取舍/过拟合候选解释，但不能证明画质恶化，因为B的FD反而更低。

当前语义实现把32个时间位置池化成128维句向量，再计算`1−cosine(video,text)`。推测它可能更容易鼓励整体主题而不是词序、数量、否定、方向和局部动作；BLEU-4下降与该解释相容，但不能证明因果。

## 3. 先做三个信息量高的诊断（P1 / D3、D5）

1. **冻结表示参考**：同一批dev比较原视频、缓存真实latent经冻结VAE解码、A-only生成、B生成的SignMbart与FD。VAE重建是参考损失，不称严格理论上界。若重建回译已很差，量化表示保真限制；若重建明显好于生成，则优先改善DiT/文本对齐。不能用旧test GT数字与当前dev横比。
2. **语义教师可靠性**：对高/中/低噪声下的真实预测x0检查教师正确文本与同长度错配文本的区分度；再与最终DDIM生成对照。记录x0损失与语义损失的梯度范数、夹角。当前末步`.05×.32355≈.01618`与MSE`.01559`同量级，但标量相近不能推导梯度冲突。教师若只在干净GT latent上有效，不应在所有噪声段强推。
3. **局部动作与长度误差**：按短/中/长句、数字/地名/天气变化词/否定分组；正确、同长度错配文本采用固定seed。另做倒序、乱序、静态重复帧对FD与教师分数的敏感性检查。B预测长度BLEU-4=0需要长度误差分桶复核，单次64条不足以判定长度头是主因。

这些诊断只读现有配对信息；不提取pose/gloss作为监督。人类目检应同时看语义和动作，条件允许时由理解手语的人核验，不把天气回译流畅当成手语正确。

## 4. 可执行的候选组合

### E1：降低并校准语义损失强度（P2 / D1、D2，最先做）

**触发**：B语义目标很强，但BLEU-4下降，教师在生成分布的可靠性未知。

**最小实验**：从同一个A5k起点、重建相同优化器与相同seed，训练5k。`λ=0/.005/.01/.02/.05`；现有A-only和B分别是0/.05，可在相同代码和数据协议下复用，新增三个中间权重。第一轮只改λ。挑选候选后单独测试噪声依赖权重`λ(t)`，按照诊断2的教师可靠区间设置，不能预设高噪声必然不该监督——高噪声也是学习从文本生成的关键阶段。

**对照与判据**：与等预算A及B同时比；BLEU-4提升、FD不退化才晋级，内部教师分数提升不算通过。正确−错配差和WER为辅助检查。若所有小λ都回到A水平，说明减弱教师仅减少扰动，应转E3而不是继续密集扫权重。

**预算**：三个5k实验。当前A/B实测每5k约33/35分钟，预估训练合计约1.5–3 GPU小时（含环境波动，不含生成回译）；新增日志/权重门控低至中实现成本。λ范围为本项目提案，不是论文最优值。

**文献**：[Text2SignDiff](https://arxiv.org/html/2509.10845v1)支持跨模态对齐作为机制，但其输出是pose；本方案只使用已有视频latent，不复用pose监督。准确的权重与噪声门控需要本地验证。

### E2：有限区间CFG与采样校准（P1–P2 / D1，最快的指标试验）

**机制来源**：[Applying Guidance in a Limited Interval…](https://arxiv.org/abs/2404.07724)在扩散模型、包括DiT上研究有限噪声区间使用CFG以改善样本与分布质量。

**最小实验**：对现有A-only和B分别固定DDIM50、seed、文本和长度，先比较CFG=1/1.5/2/3；选出候选scale后再比较全程、关闭最高噪声段、仅中间噪声段三个设置。区间外scale=1（纯条件预测）。使用log-SNR或有效噪声`σ_eff=√((1−ᾱ)/ᾱ)`定义区间；不要机械照搬论文某个采样器的步号。最后单独测试50→100步，避免同时改变所有采样参数。

**判据**：同模型FD下降且BLEU-4不恶化，才进入全dev；若只有FD改善但动作/回译退化，不作为主方案。不能用GT或SignMbart给每条视频挑seed，不能只报告best-of-N。

**预算**：第一轮8组64条生成评测，之后仅保留少量候选；不重训，成本取决于VAE解码/SignMbart吞吐，未测整套精确耗时。区间CFG需要小范围采样实现；静态scale已有入口。

### E3：独立latent→text逐词逆向监督（P2 / D2，BLEU主攻路线）

**机制来源**：[TM2T](https://arxiv.org/abs/2207.01696)用motion→text逆向对齐约束text→motion。论文是离散3D动作模型；这里迁移逆向语义约束，不迁移动作tokenizer。

**提案**：仅在train配对上训练视频latent时序编码器＋文本decoder：`z_GT→sentence`。通过dev后冻结辅助模型，计算`L_seq=−Σ log p(y_i|y_<i, x0_pred)`，梯度穿过辅助视频编码器回到预测x0。主生成mT5照常微调。与现有句向量余弦相比，逐词监督有机会约束遗漏、词语组合等BLEU相关错误，但CE不是BLEU本身，也不保证动作顺序正确。

**防止语言模型捷径**：固定相同GT文字前缀，比较正确、同长度错配、置零latent的NLL；不提供GT文字前缀时自由解码dev文本。只有teacher-forcing CE变低而视频替换无影响，教师不合格。辅助模型不得读取输入原句作为视频encoder条件；SignMbart始终仅做独立评测。

**最小实验**：先验证教师，再从同A5k分叉：等预算无语义、现有最佳句向量损失、仅逐词损失。辅助权重按少量train探针使其初始梯度约为主损失的10%/30%两档（实验起点，不是通用最佳比例），分别训练5k，避免不同loss数值量纲直接照抄λ=.05。分噪声可靠性同E1。

**判据**：BLEU-4/长句/关键词遗漏改善且FD不退化，并扩展dev/seed复核。教师不能读懂真实GT latent则停止该路线；教师可用但独立SignMbart无改善，则考虑教师分布偏移或生成器未响应，不能仅加权重。

**预算**：教师预训练＋2–3个生成分支，实现成本中高；训练/显存先用200步测吞吐，不冒充已有时长。原始文本监督可有同义表达差异，需要结合ROUGE与人工核验。

### E4：多时间尺度latent动态监督（P2 / D2，FVD主攻路线）

**机制来源**：[Human Motion Diffusion Model](https://arxiv.org/abs/2209.14916)使用x0输出以施加位置/速度等动作损失。本项目只借鉴动态一致性思想；没有关节、脚接触或pose监督，latent差分也不等于物理速度。

**提案**：在既有x0损失之外，对归一化latent加轻量`L_dyn=Σ_k ||ΔP_k(x0_pred)−ΔP_k(z_GT)||_1`；`P_k`为时间池化、k先取1/2/4。逐样本只取有效连续帧，不跨padding求差；先在可可靠重建的噪声段启用。不要只惩罚`||Δx0_pred||`，否则会奖励不动的视频。

**最小实验**：等预算A vs A+单尺度差分 vs A+多尺度差分，每组先5k。先不叠加E3；若多尺度有效再与最佳语义分支组合。动态梯度初始规模按train探针的5%/15%两档校准，属于项目试验值。

**判据**：FD下降、动态幅度未塌缩、手部时序目检变好、BLEU-4至少保持。若更平滑但动作静止/词语遗漏增加，降低或放弃。每句可能有多种合法动作节奏，对单条GT的强帧级约束会产生平均化，这是主要风险。

**预算**：额外运算较少，预计接近现有5k基线，具体以短探针为准；实现成本中。更复杂的REPA式teacher特征对齐留后续。

### E5：文本/视频双流交互（P3 / D2，结构路线）

**机制来源**：[SD3/MM-DiT](https://arxiv.org/html/2403.03206v1)为图像、文本提供独立权重并联合注意力。原文文本encoder冻结，不能把其成功归因于解冻文本encoder；本项目按用户要求保留主mT5可训练。

**触发**：现有text-prefix把文本与视频送入共享self-attention。若最小文本变化/梯度探针显示token内容或关系对动作影响弱，结构增强比继续增加句向量loss更有针对性。

**最小实验**：先在现有12层中的少量层加入模态独立QKV/FFN和可控残差（已有cross-attention，不把“再加一次cross-attn”当成新机制）；保留其余层和x0目标。测试4层双流后才决定全双流。新分支初始化需兼容原网络，并报告新增参数、显存和速度。比较原网络等预算、容量匹配控制、双流，避免把容量收益当模态交互收益。

**判据**：正确文本的绝对BLEU-4与FD改善；仅正确−错配差变大但绝对效果更差不算成功。先在少量训练句子的纯噪声生成过拟合上验证表达能力，测试集不参与；正式dev泛化另评。

**预算**：先200步吞吐和32句训练集探针，再5k/10k预筛；参数增长与多路激活会增显存，不能直接承诺35分钟。7k视频规模存在过拟合风险。

### E6：x0兼容的时间步损失重加权（P2 / D1、D2）

**机制来源**：[Min-SNR-γ](https://arxiv.org/abs/2303.09556)将不同噪声时间步作为多任务，重加权缓解冲突；[官方实现](https://github.com/TiankaiHang/Min-SNR-Diffusion-Training/blob/main/guided_diffusion/gaussian_diffusion.py)中x0权重为`min(SNR,γ)`，ε分支才另除SNR。

**最小实验**：从同A5k出发，等权x0 vs γ=5；有效时再试1/10。若按采样分布归一化权重均值以保持loss尺度，明确这是本项目变体，并且两个分支保持可比有效学习率。不在同一轮改变语义λ、t采样分布或目标参数化。

**判据**：以独立生成BLEU/FD为主，另记录噪声分桶误差。相对当前等权x0，Min-SNR会降低最高噪声权重，可能伤害从文本启动生成；高噪声语义更差则撤回。之后才研究logit-normal采样范围或JiT式等价loss配方，不能把flow matching/速度预测悄悄替换进本项目。

**预算**：1–3个5k分支，运行开销接近基线，实现成本低至中。论文ImageNet加速倍数不外推到当前手语任务。

### E7：文本预测粗时间计划，再细化视频（P3 / D2、D6，长句后备）

**触发与依据**：只有当长句/顺序分组明显差、E3教师可用但局部动作组织仍失败时才上。依据是本地可验证失败模式；本方案尚无当前1-token手语数据上的直接论文证据。

**提案**：从GT latent时间池化得到16/32个粗latent节点，训练小型text条件x0扩散器生成计划；原DiT在文本＋文本生成计划下输出完整视频x0。长度也由文本预测。粗目标完全派生自既有视频latent，不添加pose/gloss标签。

**关键对照**：单阶段vs两阶段；训练需逐步使用模型预测计划，并模拟误差，推理不可注入GT计划/GT长度。若只在oracle粗计划下好、实际预测计划下差，就是训练推理不匹配。

**预算与风险**：新增模型、两阶段训练和误差传播，最高实现成本；先只做计划可预测性/短句对照。全量开发暂不优先，避免把时间预算用在不可预测的中介上。

## 6. 推荐执行路径

**稳妥提指标**：三个诊断 → E2采样预筛 ＋ E1三个λ分支 → 候选全dev与seed复核 → 独立加E4。候选保存为独立checkpoint，训练loss和dev MSE只作诊断，不替代生成选点。

**主攻BLEU**：先验证E3的GT latent→text教师 → 句向量vs逐词监督等预算比较 → 关键词/长句误差分析 → 必要时E5。输出更像某段手语但回译未提高时，检查教师与评估器偏差，不连续增大语义权重。

**主攻FVD**：E2 → E4 → E6，每项单独与固定基线比较；保存BLEU保护指标。只变成更静止、更相似背景的“好看”视频不晋级。

首轮明确推荐：诊断＋CFG静态/区间小扫＋λ=.005/.01/.02三组5k，同时训练一个独立latent→text教师验证可行性。先不叠加全部新损失/双流/两阶段计划。E1无收益而E3教师有效时，优先从句向量换到逐词语义。

若要专门回答“继续训练是否有用”：保留B再续5k和A-only再续5k这一对等预算控制，固定设置并保留中途checkpoint；它检验训练时长，不与新方法改动混成一组。当前损失仍下降，无法仅凭曲线排除收益。

## 7. 选点与停止规则

- 不承诺BLEU/FVD提高的幅度。目标是全dev上BLEU-4更高、FD更低；若取舍则保留Pareto候选并明确代价，不能只摘取更好的指标。
- 64条结果用于淘汰明显坏配置，不足以确认+.53 BLEU-1或−1.35 FD有效。补BLEU-4 paired bootstrap；最终三个训练seed分别报告均值/标准差，生成seed和训练seed分开。
- 参数/采样改变时固定视频、anchor、长度模式和评测器。先单因素，再做最佳语义＋最佳动态损失的2×2组合，检验是否有相互抵消。
- 不用SignMbart训练或挑选单条样本，避免直接迎合评估器；不使用test选择架构/超参。
- 每条路线两档合理超参都无外部指标收益时转下一条；教师不能通过视觉依赖测试则停该教师路线，不把它注入DiT。
- 独立新子系统需要进一步实现设计；当前仅给实验方案与机制证据。无需用投稿等级或论文宣传效果替代项目实测。
