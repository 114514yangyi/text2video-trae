## Actionable findings

1. **P2 — bind generation and scoring to one data/decoder configuration.** `tools/eval_milestone.py:130–134` only compares the requested sampling settings to the checkpoint settings. Dataset samples, manifest, and FVD real-frame root are taken from `--config` (`:105`, `:134`, `:147`, through `fvd_command` at `:73–74`), but `MilestonePipeline` takes its normalizer, VAE, and source reference-frame root from the checkpoint (`t2v/pipelines/milestone.py:85`, `:102–103`, `:111–115`, `:169–170`). A checkpoint and requested config with identical sampling but different `data.cache`, `data.stats`, `data.frame_root`, or `vae` settings pass all current checks. The resulting generation can combine cached reference features/text from one source with a reference image from another, and then score against a third real-frame root. IDs and frame counts can all agree, so the trajectory-length assertion does not catch this. Reject incompatible source/decoder contracts before generating output, comparing resolved paths or verified contract identities; alternatively make the checkpoint configuration authoritative for every generation and scoring input and record that effective configuration. Add a regression where sampling agrees but source or decoder settings differ and assert fail-fast behavior. Do not require unrelated run settings such as output directory to match.

2. **P2 — skip ineligible real clips before checking generated length.** `tools/eval_fvd.py:390–395` calls `paired_paths` before testing the real clip against `min_frames`. In contiguous24 mode, a genuine 23-frame source with its correctly generated 23-frame counterpart now raises at `:214–215`, although §2.1 requires short source videos to be skipped. The new milestone wrapper avoids this only because its manifest prefilters those sources; the public official FVD CLI still allows an unfiltered generated test tree or IDs list and should implement the same eligibility rule. Check source eligibility before applying generated-length requirements, while retaining strict failure for an eligible 24+-frame source whose generated clip has fewer than 24 frames. Add both cases to the regression coverage. The skipped IDs should remain explicit in output metadata.
