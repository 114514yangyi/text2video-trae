**口播稿**

这一页是本次组会汇报的封面，主题是从德语文本直接生成手语视频。整个方法建立在两个前提上：一是冻结的 VAE 把每一帧画面压成一个 1024 维的 token，二是扩散过程在这个 latent 空间里进行，全程没有 pose 中介、也没有 pose 监督，条件只来自文本。左下角的数字是当前表现最好的实验 prefix_120k 的结果：在单侧测试集上 BLEU-4 是 3.18，BLEU-1 是 12.55，ROUGE-L 是 12.60，WER 是 100.5，检索指标 MRR 是 0.0336，也就是零信息地板的 3.06 倍。右下角这条真实视频抽帧来自 PHOENIX14T，用来说明我们要生成的对象长什么样。本期汇报按三段展开：模型架构与向量数据流、参数与模型表现，以及当前困难点。

## 03 课题与方法硬约束

**页面内容**

- **任务**：德语文本 → 手语视频（RWTH-PHOENIX-Weather 2014T）
- **数据**：可用训练片段 7021 条（max_num_frames=256 过滤后）；平均句长约 110 帧
- **硬约束①**：冻结 VAE —— 生成必须基于已训练好的 1-token（每帧 1024 维）VAE，不换 tokenizer
- **硬约束②**：潜空间扩散 —— 扩散在 VAE latent 空间进行，不回到像素态
- **硬约束③**：x-prediction —— 网络预测干净 latent x0，噪声或速度只作等价换算
- **硬约束④**：纯文本条件 —— 条件只能来自文本；部署所需长度也由文本预测，VAE 解码锚点属冻结 VAE 固有输入
- **口径**：PHOENIX14T · 25 fps · 256×256

**口播稿**

这一页交代任务定义和四条必须同时成立的方法硬约束。任务是德语文本到 RWTH-PHOENIX-Weather 2014T 手语视频，按每一段不超过 256 帧过滤之后，可用训练片段只有 7021 条，平均句长大约 110 帧，数据规模是偏小的。第一条硬约束是生成必须基于已经训练好的 1-token VAE，每一帧压成 1024 维，不能更换 tokenizer。第二条是扩散必须在 VAE 的 latent 空间里做，不能回到像素空间。第三条是必须使用 x-prediction，也就是网络直接预测干净的 latent。第四条是纯文本条件，不能引入 pose、参考帧或光流等额外监督；部署时需要的视频长度也由文本预测，真实视频的第一帧只是冻结 VAE 解码时本来就需要的锚点，不算新增条件。

## 04 模型架构图

**页面内容**

- **① 冻结 VAE 编码**（离线执行 · 只读缓存）：输入 视频帧 [B,T,3,256,256]；输出 latent [B,T,1024]
- **② DiT-B 主干**（可训练 · 约 1.81 亿参数）：输入 归一化带噪 latent [B,T,1024]；输出 预测干净 latent x0 [B,T,1024]
- **③ 冻结 VAE 解码**（仅生成 / 可视化时加载）：输入 干净 latent [B,T,1024] ＋ 参考帧特征 [128,512] ＋ GT 首帧 [1,3,256,256]；输出 视频帧 [B,T,3,256,256]
- **条件支路 · 文本**：德语文本 [B] → mT5-base → token 嵌入 [B,120,768] → 前缀 token [B,120,768]
- **条件支路 · 长度**：池化文本 [B,768] → 长度头（8 桶）→ 帧数 [B] → log 归一化 [B,1] → MLP
- **图例**：灰 = 冻结（不可训练）；蓝 = 可训练
- **形状记号**：B = batch · T = 帧数（运行时可变）· 1024 = latent 维 · 768 = 主干隐藏维

**口播稿**

这一页是整条链路的架构图，横向分三段，从左到右看。第一段是冻结的 VAE 编码，离线执行，与相邻项目共用同一条 TiTok-CVAE，输入的向量形状是 B×T×3×256×256，也就是 batch 乘帧数乘三通道乘 256 乘 256 的像素，输出是 B×T×1024 的 latent，每一帧就一个 1024 维 token，这部分是灰底，表示冻结、不可训练。第二段是 DiT-B 主干，全链路里唯一可训练的部分，参数量约 1.81 亿，输入是归一化后加过噪的 latent，形状 B×T×1024，输出是它预测的干净 latent x0，形状同样是 B×T×1024。第三段是冻结的 VAE 解码，只在生成和可视化时加载，输入除了干净的 latent，还要加上参考帧特征 128×512 和真实视频第一帧 1×3×256×256 作为解码锚点，输出还原成 B×T×3×256×256 的视频帧。下面这一行是条件支路，条件只来自文本：德语文本先经过 mT5-base，变成 token 嵌入 B×120×768 和前缀 token B×120×768；另一路把池化文本 B×768 送进长度头，预测出帧数，再做 log 归一化变成 B×1，经过一个 MLP 变成长度向量 B×768。两条支路都汇入主干：前缀 token 进自注意力，池化文本和长度向量合成的条件向量 c 用来驱动每一层。右下角是图例和形状记号：灰表示冻结、蓝表示可训练，B 是 batch、T 是运行时变化的帧数、1024 是 latent 维、768 是主干隐藏维。

## 05 向量数据流

**页面内容**

- **① 文本编码**：输入 token id [B,120]；输出 token 嵌入 [B,120,768]；＋ mask [B,120]（冻结 mT5-base）
- **② 条件投影**：输入 嵌入 [B,120,768]、帧数 [B]；输出 前缀 [B,120,768]；池化 [B,768] + 长度 [B,768] → c [B,768]
- **③ 加噪与归一化**：输入 latent x0 [B,T,1024]；输出 带噪 latent [B,T,1024]；cosine 调度 · logit-normal 采 t
- **④ 帧嵌入**：输入 带噪 latent [B,T,1024]；输出 帧隐状态 [B,T,768]；Linear(1024→768) ＋ 位置编码
- **⑤ 12 × DiTBlock**：输入 联合序列 [B,120+T,768]；输出 切回帧 [B,T,768]；文本前缀与帧 token 同场自注意力
- **⑥ 输出层 FinalLayer**：输入 帧隐状态 [B,T,768]；输出 预测 latent x0 [B,T,1024]；adaLN 调制 ＋ 零初始化线性
- **每层内部**：adaLN-Zero (4608,768) → self-attn qkv (2304,768) → cross-attn (2304,768) → MLP fc1 (3072,768)
- **解码**：x0 [B,T,1024] → 反归一化 [B,T,1024] → 冻结 VAE 解码 → 视频帧 [B,T,3,256,256]
- **形状来源**：runs/prefix_120k/final.pt 权重：x_embedder (768,1024) · type_embed (2,768) · pos_embed (1,512,768)

**口播稿**

这一页把上页的分块拆开，逐个节点标出输入和输出的张量形状，分六步看。第一步文本编码：输入是 token id，形状 B×120，经过冻结的 mT5-base，输出 token 嵌入 B×120×768，同时带一个 mask B×120。第二步条件投影：输入是嵌入 B×120×768 和帧数，输出是前缀 token B×120×768，以及池化向量 B×768 和长度向量 B×768，两者相加得到条件向量 c，形状 B×768。第三步加噪与归一化：输入是干净 latent x0，形状 B×T×1024，按 cosine 调度加噪、时间步用 logit-normal 采样，输出带噪 latent，形状不变，还是 B×T×1024。第四步帧嵌入：带噪 latent 经过一个 1024 到 768 的线性层，再加位置编码，输出帧隐状态 B×T×768。第五步是 12 层 DiTBlock：文本前缀和帧 token 拼成一条联合序列，形状 B×(120+T)×768，在同一场自注意力里互相可见，走完 12 层再切回帧的部分，输出 B×T×768。第六步输出层 FinalLayer：输入帧隐状态 B×T×768，输出预测的干净 latent x0，形状 B×T×1024。页面底部补充了每层内部的权重形状，以及解码这一步：x0 反归一化之后，交给冻结 VAE，配合参考帧特征和真实首帧，解码成视频帧 B×T×3×256×256。这里的形状都是从 prefix_120k 的权重文件里读出来的，比如帧嵌入层是 768×1024，类别嵌入是 2×768，位置编码是 1×512×768。
